# Practical 6: Chain Matrix Multiplication

## Summary
The 6th practical implements the **Chain Matrix Multiplication** problem using dynamic programming to find the minimum number of scalar multiplications needed to compute a sequence of matrix products. The solution uses a 2D DP table to explore all possible parenthesization orders and determine the optimal one that minimizes the total computational cost.

## Conclusion
This practical demonstrates how dynamic programming efficiently solves the optimization problem of matrix chain multiplication. By breaking down the problem into overlapping subproblems and storing their solutions, the algorithm achieves O(n³) time complexity, which is far superior to the exponential brute-force approach. This showcases the power of dynamic programming in tackling complex algorithmic challenges.
