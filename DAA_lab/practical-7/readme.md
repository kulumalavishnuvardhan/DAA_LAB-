Summary:
This program uses Dynamic Programming to solve the Coin Change problem by finding the minimum number of coins needed to make a given amount. It builds a DP table to store optimal solutions for smaller amounts and measures the execution time of the algorithm. The approach avoids redundant calculations and efficiently computes the result.

Conclusion:
Dynamic Programming provides an optimal and efficient solution to the Coin Change problem with a time complexity of O(N × Amount) and a space complexity of O(Amount). It is more effective than recursive approaches for larger inputs because it stores and reuses previously computed results. This makes the algorithm both practical and scalable for real-world applications.
