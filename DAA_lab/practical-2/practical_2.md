# Practical 2: Linear Search and Binary Search

## Summary
Linear search and binary search are two common methods for finding an element in a list. Linear search checks each element from the beginning to the end until the desired value is found, so it is easy to understand and works for both sorted and unsorted data. Its worst-case time complexity is O(n), which means it may take longer when the list becomes large. Binary search is more efficient because it works only on sorted data and repeatedly divides the list into halves to locate the target value. This reduces the number of comparisons and gives a time complexity of O(log n), especially in large sorted datasets.

## Conclusion
In conclusion, linear search is suitable for small data sets or when the data is not sorted, because it is simple and does not require any preparation. Binary search is better for large sorted lists because it performs searching much faster and uses fewer comparisons. Therefore, linear search is easier to implement but less efficient, while binary search is faster and more practical for sorted collections.
