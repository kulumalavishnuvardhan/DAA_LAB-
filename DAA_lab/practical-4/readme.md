Summary:
This program calculates the factorial of a non-negative integer using both iterative and recursive approaches. It measures and compares the execution time of each method and displays the factorial result. Both approaches have a time complexity of O(n), while their space complexities differ.

Conclusion:
The iterative method is generally more efficient because it uses constant memory (O(1) space). The recursive method is simpler and demonstrates recursion concepts but requires additional stack space (O(n)). For larger inputs, the iterative approach is usually preferred due to its better memory efficiency
